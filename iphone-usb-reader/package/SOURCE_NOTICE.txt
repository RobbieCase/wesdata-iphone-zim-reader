Local modifications for this emergency build:
- Bundled the reader UI, English translation, styles, and JavaScript into one
  HTML payload so Safari can load it from a user-selected file.
- Disabled the libzim worker path and enabled Kiwix JS restricted/pure-JS mode.
- Forced the bundled ASM XZ and Zstandard decoders so no external WASM file or
  web server is required.
- Replaced external iframe pages and image references with embedded equivalents.
- Added a small Safari bootstrap page and optional Apple Shortcuts injection.

The local changes are included as MODIFIED_SOURCE.patch and the bundling script
is included in the repository as iphone-usb-reader/build.mjs. This preservation
repository already contains the modified source. Run `npm ci`, then
`npm run build-min`, then `node iphone-usb-reader/build.mjs` from the repository
root to regenerate the package.
