Open a ZIM on iPhone without Kiwix.

This proof of concept uses only Files and Safari. It installs nothing system-wide and does not contact the internet.

Try the smallest archive first

  1. Connect WESDATA and open Files → Browse → Locations → WESDATA.
  2. Open 90_OFFLINE_READERS → IPHONE_EXPERIMENTAL → IPHONE_OFFLINE_START_URL.txt.
  3. Select All and Copy the one long line. Paste it into Safari's address bar and tap Go.
  4. Tap Load reader, then select IPHONE_ZIM_READER_PAYLOAD.html from this folder.
  5. If Safari says ServiceWorker mode is unsupported, tap Okay. This intentionally selects the included Restricted mode.
  6. In the reader, choose this small test archive:
    02_EMERGENCY_AND_SURVIVAL/Offline_Archives/Knots_illustrated_2026-07.zim
What is happening? The address contains a tiny offline launch page. That page reads the 2 MB reader from the USB into Safari. The reader then reads the selected ZIM directly from the drive.

Expect rough edges

This is an unofficial experiment, not an iPhone app. Smaller, encyclopedia-style archives are the best fit. Multi-gigabyte archives may be slow or exceed the phone's available memory; interactive sites may render partly. The Knots index and its full Bowline article were tested directly from this USB copy. If another test fails, retry with Knots before assuming the drive is damaged.

Safety: Only select trusted files from WESDATA. Offline medical and emergency material may become outdated; use current professional help and official directions whenever available.

If Safari searches instead

Copy the complete line, including data:text/html;base64,, and paste it into Safari's address bar—not a webpage search box. If Safari closes the page, repeat the five steps; nothing needs reinstalling.

The optional Shortcut is only a more convenient launcher. The plain URL method is the fewest-moving-parts fallback. See MANUAL_SHORTCUT_RECIPE.txt for the advanced setup.
